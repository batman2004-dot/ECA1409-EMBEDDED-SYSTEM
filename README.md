Embedded Systems Lab – Experiments 1 to 18

This repository contains Embedded Systems laboratory experiments 1 to 18, implemented using Arduino, Proteus, and Keil µVision5.

🛠️ Software Used

- Arduino IDE – Experiments 1 to 10
- Proteus – Circuit design and simulation for Experiments 1 to 10
- Keil µVision5 – Experiments 11 to 18
- Embedded C – Programming language for Keil-based experiments

🎯 Objective

The objective of these experiments is to understand Arduino programming, circuit simulation, microcontroller programming, and embedded C programming.

💻 Tools

Arduino IDE: Used for programming Arduino-based experiments.

Proteus: Used to design and simulate circuits for Experiments 1–10.

Keil µVision5: Used for writing, compiling, and testing embedded C programs for Experiments 11–18.

📌 Note

All programs and simulations are provided for educational and laboratory purposes.
